Before you paste anything into an LLM

Prompt structure.

Seven layers — stack them in this order and watch generic AI become your AI.

01Identity
Role.

Tell it who to be. An expert. A coach. A skeptic. The right role changes everything.

# You are a senior brand strategist…

02Action
Task.

Use a clear action verb. Break complex jobs into steps. Tell it what to do, not just what you want.

# Analyze · Generate · Critique · Compare

03Guardrails
Specifics.

Format. Length. Tone. The constraints that make the output usable.

# 150 words · Friendly · Bullet list

04Background
Context.

Who is this for? Why does it matter? Context turns a generic answer into yours.

# Our audience is entrepreneur dads…

05Pattern
Examples.

Two or three input → output samples. Show, don't just tell. This alone doubles quality.

# Example 1: Q… A…   # Example 2: Q… A…

06Reminders
Notes.

Edge cases. Tone reminders. The "by the way" that prevents drift.

# Avoid jargon · Default to neutral if unclear

07Form
Markdown.

Use # headers for each section. **bold** for emphasis. The LLM reads structure like a human reads paragraphs.

# Role  # Task  # Specifics  # Context

Stack the layers. Save the prompt. Reuse it forever.
